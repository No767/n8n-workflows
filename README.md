# n8n-workflows

Self-hosted instance of [n8n.io](https://n8n.io/), but configured exclusively for me.

This was created as I got sick of manually keeping track of university assignments that I would miss on Canvas because there no push reminder for due dates (and even using Google Calendar only has caused more clutter and hasn't helped at all), or I wouldn't know if there was a new assignment that was due, etc. Thus, this is hopefully the fix to that.
